The final public MCP suite and prior ordinary-browser regression are retained separately from the rejected virtual Ctrl+A implementation. `unsafe-primary-results.json` records the old synthetic password becoming PRIMARY (`primary_is_initial_secret:true`), with no password bytes in output. The final route uses controlled DOM selection and native insertion; its result/history/report payloads are in `final-responses.json.gz` and contain no synthetic secret marker.

`selection_probe.py` is the exact independent comparison executed in a private Xvfb/D-Bus session as UID1001 with sandboxed Chromium153 and the provisioned Playwright1.63 environment. It hardcodes that test browser's `/workspace/silo-desktop-research/browsers/chromium-1243/chrome-linux-arm64/chrome` path. It creates only synthetic password fields, compares virtual Ctrl+A versus exact DOM range/select, reads PRIMARY only in this independent test oracle, and prints booleans/byte counts. Run only under a fresh private ordinary-account Xvfb session; do not point it at a shared desktop or an existing browser/profile. The original output is `selection_probe.log`. The production secret route never reads clipboard contents.

`failed-attempts.json.gz` preserves source-bound failed matrix reports, including fixture construction/sequencing errors and the substantive PRIMARY disclosure. No failed run is rewritten. The final19-check report does not claim another browser version or arbitrary application-controlled masking is safe. See `docs/OWNED-BROWSER-SECRET.md` for the contract and limitations.
