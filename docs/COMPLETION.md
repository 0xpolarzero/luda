# Standalone completion checklist

- [x] Standalone plugin, skill and MCP tools; remove application-manager integration assets and preserve Git history.
- [x] Generic Linux installation, explicit account/session selection, direct execution in an existing graphical environment.
- [x] Document native X11 prerequisites, tested environments, unsupported Wayland/Xwayland and application-provider limitations.
- [x] Verify core observation, targeting, text, pointer/keyboard, window/workspace, cancellation and recovery workflows.
- [x] Validate plugin registration, installed MCP execution, wheel/source contents and exact runtime/skill integrity.
- [x] Separate product behavior, fixture defects and unsupported environments; retain original failures and test the narrow harness corrections.
- [x] Freeze the existing computer-use inventory; no new integration projects or speculative feature expansion.

[Validation](VALIDATION.md) records exact source versions, local/hosted results and remaining CI rerun status. The supported core is usable and locally verified. This is not a claim of universal desktop support, composition-safe native editing for every application, or a guarantee against simultaneous human input.
