# Optional local screenshot OCR

`desktop_ocr(snapshot_id, language="eng", limit=200)` reads word candidates from the exact image returned by an earlier `desktop_observe`. It never captures a replacement image, sends input or verifies application text. Candidate `image_bounds` use the returned screenshot's pixels, including any resizing; they are not native root coordinates. `engine_confidence` is Tesseract's 0–100 score, explicitly uncalibrated and not a probability or guarantee of correctness.

The snapshot must belong to this server, remain younger than 15 seconds and retain its pixels. Changed window/popup layout or display topology is refused before and after OCR. Unchanged layout does not imply unchanged content: results describe historical pixels even if the app has since edited its text. Observe again deliberately when current content matters, and verify intended targets before input.

Tesseract is optional and local. Doctor's `ocr.available` reports executable availability only; it does not enter overall `ready` or qualify installed languages/recognition. On Ubuntu an administrator can explicitly install `tesseract-ocr` and `tesseract-ocr-eng`; these packages are not added to Luda's runtime installer. `OCR_UNAVAILABLE` and `OCR_LANGUAGE_UNAVAILABLE` leave other capabilities usable. `language` selects one installed model (such as `eng`); combined models are not currently supported. The missing-language error supplies a bounded installed-model list.

The implementation follows the [official Tesseract CLI documentation](https://tesseract-ocr.github.io/tessdoc/Command-Line-Usage.html): TSV supplies word boxes/confidence, and sparse-text page segmentation is fixed at mode 11. Input PNG bytes go to stdin; TSV comes from stdout. There are no caller-selected paths, cloud requests, model credentials, recognition profiles or automatic actions. Bounds are 6,553,600 input pixels, 32 MiB input bytes, a two-second language probe, five-second recognition, 1 MiB combined recognition output, 20,000 TSV rows, and 1–1,000 returned candidates. Results identify truncation. Cancellation uses the existing bounded process-group cleanup path. Engine failures do not echo arbitrary stderr or screenshot text in error messages.

Observation now retains screenshot PNG bytes in memory for OCR: at most 16 snapshots and 32 MiB total, with oldest snapshots evicted when needed. An oversized single image retains pointer metadata without OCR pixels. Expired entries are removed on the next observation/OCR access, or all entries on close/reconnect; expiry is a validity limit, not a background deletion timer. There are no default OCR logs or saved screenshot archives. Existing temporary screenshot/input staging is cleaned by the existing capture/subprocess lifecycle.

## Local evidence

`tests/test_ocr.py` covers TSV geometry/confidence/truncation, malformed/nonnumeric/out-of-bounds output, missing engine/model, arguments and limits, fixed stdin/stdout invocation, error privacy, actual subprocess cancellation without a delayed effect, cache budgets, stale snapshot/layout handling and the read-only tool schema.

`tests/live_ocr.py` ran as UID 1001 on private Xvfb/XFWM/D-Bus, with Ubuntu Tesseract **5.3.4** (`5.3.4-1build5`) and English trained data (`1:4.1.0-2`). It recovered `LUDA`, `ORBIT`, and `4271` from a real GTK/Pango canvas. Returned boxes matched independent Pango ink rectangles within five resized-image pixels. After the screenshot, the fixture changed its rendered text without changing layout; OCR still returned the original screenshot words, proving historical source rather than silent recapture. A missing model left doctor ready, and moving the window caused stale-snapshot refusal. All three live assertions passed; raw evidence is under `artifacts/ocr/` in the qualification worktree and `/workspace/luda-ocr-live.log`.

This English high-contrast fixture does not qualify every script, font, handwriting, rotated text or low-quality capture. Empty/mistaken OCR remains possible and must never become a claim of exact text or safe automatic input. MEDIA-07 remains release-unqualified.
